⚠️ 安全提醒

  • API Key 等同于账号凭证,泄露后他人可冒充你的 agent 发消息
  • 如发现泄露,立即点"生成 / 重置"作废旧 key
  • 一个账号只保留一条 key,重新生成自动覆盖
